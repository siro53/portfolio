## 目次

## できること

> 長さ $N$ の数列 $x$ がある。以下のクエリをどちらも $O(\log N)$ で処理できる。
>
> (1) 区間 $[l, r)$ の各要素 $x_l, x_{l+1}, \dots, x_{r-1}$ にそれぞれ値 $v$ を加算する。$(0 \leq l < r \leq N)$
>
> (2) $\sum_{i=0}^{r-1} x_i$ を計算する。

## アルゴリズム

長さ $N+1$ の BIT を 2 つ持つ。（それぞれ $B_0, B_1$ とする）

### (1) のクエリの場合

- $B_0[l]$ に $-v \times l$、$B_0[r]$ に $v \times r$ を足す。
- $B_1[l]$ に $v$、$B_1[r]$ に $-v$ を足す。

### (2) のクエリの場合

$B_0$ の $[0, r)$ の和を $s_0$、$B_1$ の $[0, r)$ の和を $s_1$ とすると、$s_0 + r s_1$ が答え。

### 証明？

(1) のクエリが飛んできた後に (2) のクエリで正しく計算できていれば良い。
(1) で $[a, b)$ に値 $v$ が加算され、(2) で $[0, c)$ の和を求めるとする。

**$c < a$ の時**

(1) のクエリで加算された値は $[0, c)$ には関係ないので OK。

**$a \leq c < b$ の時**

- $B_0$ の $[0, c)$ に加算された値は $-va$
- $B_1$ の $[0, c)$ に加算された値は $v$

よって、$s_0 + c s_1 = v(c - a)$ より、正しい。

**$b \leq c$ の時**

- $B_0$ の $[0, c)$ に加算された値は $-va + vb$
- $B_1$ の $[0, c)$ に加算された値は $-v + v = 0$

よって、$s_0 + c s_1 = v(b - a)$ より、正しい。

以上より、正しく区間和を計算できている。
