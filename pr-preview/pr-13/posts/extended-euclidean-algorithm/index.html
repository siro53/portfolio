ユークリッドの互除法

ユークリッドの互除法は、次の性質を用いて 2 つの整数 a,ba, ba,b の最大公約数を求めるアルゴリズムである。

2 つの整数 a,ba, ba,b に対して整数 q,rq, rq,r が存在して、a=bq+ra = bq + ra=bq+r と書ける時、 gcd⁡(a,b)=gcd⁡(b,r)\gcd(a, b) = \gcd(b, r)gcd(a,b)=gcd(b,r) が成り立つ。

証明

b,rb, rb,r の最大公約数を g0g_0g0​ とする。この時、bqbqbq は g0g_0g0​ の倍数である。 よって、bq+rbq + rbq+r は g0g_0g0​ の倍数であり、これは aaa に等しいので g0g_0g0​ は aaa の公約数。 ゆえに gcd⁡(b,r)≤gcd⁡(a,b)\gcd(b, r) \leq \gcd(a, b)gcd(b,r)≤gcd(a,b) が成り立つ。

また、a,ba, ba,b の最大公約数を g1g_1g1​ とする。この時、bqbqbq も g1g_1g1​ の倍数である。 よって、a−bqa - bqa−bq も g1g_1g1​ の倍数であり、これは rrr に等しいので g1g_1g1​ は rrr の公約数。 ゆえに gcd⁡(a,b)≤gcd⁡(b,r)\gcd(a, b) \leq \gcd(b, r)gcd(a,b)≤gcd(b,r) が成り立つ。

以上より、gcd⁡(a,b)=gcd⁡(b,r)\gcd(a, b) = \gcd(b, r)gcd(a,b)=gcd(b,r) である。 また、以上のことから gcd⁡(a,b)=gcd⁡(a,b−a)=gcd⁡(a,a+b)\gcd(a, b) = \gcd(a, b - a) = \gcd(a, a + b)gcd(a,b)=gcd(a,b−a)=gcd(a,a+b) が成り立つことも分かる。

この性質を用いて a,ba, ba,b を b,rb, rb,r に置き換え、繰り返し適用する。 rrr は aaa を bbb で割った余りだから r<br < br<b であり、繰り返し適用するといずれ余りが 000 になる。 よってこのアルゴリズムは有限回で停止し、r=0r = 0r=0 の時の bbb の値が最大公約数になっている。 計算量は O(log⁡(max⁡(a,b)))O(\log{(\max(a, b))})O(log(max(a,b))) であることが知られている。（ラメの定理）

コードは以下の通り：

def gcd(a: int, b: int) -> int:
    r = a % b
    if r == 0:
        return b
    return gcd(b, r)

拡張ユークリッドの互除法

ユークリッドの互除法を用いて、等式 ax+by=gcd⁡(a,b)ax + by = \gcd(a, b)ax+by=gcd(a,b) を満たす解 (x,y)(x, y)(x,y) を見つけることができる。 これを拡張ユークリッドの互除法という。また、ax+by=gcd⁡(a,b)ax + by = \gcd(a, b)ax+by=gcd(a,b) は ベズーの等式 と呼ばれる。 両辺を gcd⁡(a,b)\gcd(a, b)gcd(a,b) で割ることができるため、一般性を失わずに問題は次のように置き換えられる：

2 つの互いに素な整数 a,ba, ba,b に対して、 ax+by=1ax + by = 1ax+by=1 を満たす整数解 (x,y)(x, y)(x,y) を 1 つ出力せよ。

なお、もし解 (x,y)(x, y)(x,y) が存在する時 (x−b,y+a)(x - b, y + a)(x−b,y+a) もしくは (x+b,y−a)(x + b, y - a)(x+b,y−a) も解であるため、解は存在するならば無数に存在する。

次に、この解を求めるアルゴリズムを説明する。 再帰関数を用いて求める方法と、非再帰で求める方法の 2 通りある。

再帰

a=bq+ra = bq + ra=bq+r を用いると、上の等式は

(bq+r)x+by=1(bq + r)x + by = 1(bq+r)x+by=1

と変形できる。整理すると、b(qx+y)+rx=1b(qx + y) + rx = 1b(qx+y)+rx=1 となる。X=qx+y,Y=xX = qx + y, Y = xX=qx+y,Y=x とおくと、

bX+rY=1bX + rY = 1bX+rY=1

となり、これを再帰的に適用することでユークリッドの互除法と同じ議論でいずれ r=0r = 0r=0 になり、解 X,YX, YX,Y が求まる。 X=qx+y,Y=xX = qx + y, Y = xX=qx+y,Y=x から x=Y,y=X−qYx = Y, y = X - qYx=Y,y=X−qY と復元できるので、元の解 x,yx, yx,y が求まる。

疑似コードは以下。

# ax+by=1 の整数解 (x, y) を求める。gcd(a, b) = 1 である必要がある。
def extend_gcd(a: int, b: int) -> Tuple[int, int]:
    if b == 0:
        assert a == 1
        return 1, 0
    q, r = a // b, a % b
    X, Y = extend_gcd(b, r)
    return Y, X - q * Y

非再帰

2 つの式

axs+bys=saxt+byt=t\begin{aligned} a x_s + b y_s &= s \\ a x_t + b y_t &= t \end{aligned}axs​+bys​axt​+byt​​=s=t​

を管理する。s,ts, ts,t に対してユークリッドの互除法を適用することを考える。 u=s mod tu = s \bmod tu=smodt とおき、これに対する式 axu+byu=ua x_u + b y_u = uaxu​+byu​=u を考える。 u=s−⌊s/t⌋⋅tu = s - \lfloor s/t \rfloor \cdot tu=s−⌊s/t⌋⋅t より、

axu+byu=(axs+bys)−(axt+byt)⌊s/t⌋=a(xs−⌊s/t⌋xt)+b(ys−⌊s/t⌋yt)\begin{aligned} a x_u + b y_u &= (a x_s + b y_s) - (a x_t + b y_t) \lfloor s/t \rfloor \\ &= a(x_s - \lfloor s/t \rfloor x_t) + b(y_s - \lfloor s/t \rfloor y_t) \end{aligned}axu​+byu​​=(axs​+bys​)−(axt​+byt​)⌊s/t⌋=a(xs​−⌊s/t⌋xt​)+b(ys​−⌊s/t⌋yt​)​

よって、

xu=xs−⌊s/t⌋xtyu=ys−⌊s/t⌋yt\begin{aligned} x_u &= x_s - \lfloor s/t \rfloor x_t \\ y_u &= y_s - \lfloor s/t \rfloor y_t \end{aligned}xu​yu​​=xs​−⌊s/t⌋xt​=ys​−⌊s/t⌋yt​​

が成り立つ。 以上より、初期条件を

a⋅1+b⋅0=aa⋅0+b⋅1=b\begin{aligned} a \cdot 1 + b \cdot 0 &= a \\ a \cdot 0 + b \cdot 1 &= b \end{aligned}a⋅1+b⋅0a⋅0+b⋅1​=a=b​

とし、(s,t)(s, t)(s,t) を (t,u)(t, u)(t,u) に置き換えることを繰り返し適用することで解が求まる。

疑似コードは以下。

# ax+by=1 の整数解 (x, y) を求める。gcd(a, b) = 1 である必要がある。
def extend_gcd(a: int, b: int) -> Tuple[int, int]:
    x_s, y_s, s = 1, 0, a
    x_t, y_t, t = 0, 1, b
    while t != 0:
        temp = s // t
        u = s - temp * t
        x_u = x_s - temp * x_t
        y_u = y_s - temp * y_t
        x_s, y_s, s = x_t, y_t, t
        x_t, y_t, t = x_u, y_u, u
    assert s == 1  # s = gcd(a, b)
    return x_s, y_s

拡張ユークリッドの互除法で得られる解の値域

互いに素な 2 つの整数 a,ba, ba,b に対して ax+by=1ax + by = 1ax+by=1 を満たす整数解を拡張ユークリッドの互除法で求めた時、 その整数解は ∣x∣≤∣b∣,∣y∣≤∣a∣|x| \leq |b|, |y| \leq |a|∣x∣≤∣b∣,∣y∣≤∣a∣ を満たす。

証明

一般性を失わず a>b>0a > b > 0a>b>0 とする。

(1) 拡張ユークリッドの互除法を繰り返し用いて b=0b = 0b=0 となる 1 つ前のステップについて考える。 つまりある整数 q≥1q \geq 1q≥1 が存在して a=q,b=1a = q, b = 1a=q,b=1 が成り立つ時を考える。 この時、解は (0,1)(0, 1)(0,1) なので、∣0∣≤∣b∣,∣1∣≤∣a∣|0| \leq |b|, |1| \leq |a|∣0∣≤∣b∣,∣1∣≤∣a∣ より成立。

(2) a=qb+r (0≤r<b)a = qb + r\space(0 \leq r < b)a=qb+r (0≤r<b) とする。bz+rw=1bz + rw = 1bz+rw=1 を満たす解 (z,w)(z, w)(z,w) が存在し、∣z∣≤∣r∣,∣w∣≤∣b∣|z| \leq |r|, |w| \leq |b|∣z∣≤∣r∣,∣w∣≤∣b∣ が成り立つと仮定する。

ax+by=1(qb+r)x+by=1b(qx+y)+rx=1\begin{aligned} ax + by &= 1 \\ (qb + r)x + by &= 1 \\ b(qx + y) + rx &= 1 \end{aligned}ax+by(qb+r)x+byb(qx+y)+rx​=1=1=1​

から x=w,y=z−qwx = w, y = z - qwx=w,y=z−qw である。 仮定より、∣x∣=∣w∣≤∣b∣|x| = |w| \leq |b|∣x∣=∣w∣≤∣b∣。 また、∣y∣=∣z−qw∣≤∣z∣+∣qw∣≤∣r∣+∣qb∣=∣a∣|y| = |z - qw| \leq |z| + |qw| \leq |r| + |qb| = |a|∣y∣=∣z−qw∣≤∣z∣+∣qw∣≤∣r∣+∣qb∣=∣a∣。 故に ∣x∣≤∣b∣,∣y∣≤∣a∣|x| \leq |b|, |y| \leq |a|∣x∣≤∣b∣,∣y∣≤∣a∣。

(1)(2) より帰納的に ∣x∣≤∣b∣,∣y∣≤∣a∣|x| \leq |b|, |y| \leq |a|∣x∣≤∣b∣,∣y∣≤∣a∣ が成り立つ。

このことは、

  • 拡張ユークリッドの互除法で求める解は絶対値が最小の解であること
  • 拡張ユークリッドの互除法の各ステップで出てくる変数の絶対値は必ず max⁡(∣a∣,∣b∣)\max(|a|, |b|)max(∣a∣,∣b∣) 以下であること

を意味する。特に後者の性質はオーバーフローを考慮するときに大切な性質である。
