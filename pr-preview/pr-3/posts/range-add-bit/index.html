できること

長さ NNN の数列 xxx がある。以下のクエリをどちらも O(log⁡N)O(\log N)O(logN) で処理できる。

(1) 区間 [l,r)[l, r)[l,r) の各要素 xl,xl+1,…,xr−1x_l, x_{l+1}, \dots, x_{r-1}xl​,xl+1​,…,xr−1​ にそれぞれ値 vvv を加算する。(0≤l<r≤N)(0 \leq l < r \leq N)(0≤l<r≤N)

(2) ∑i=0r−1xi\sum_{i=0}^{r-1} x_i∑i=0r−1​xi​ を計算する。

アルゴリズム

長さ N+1N+1N+1 の BIT を 2 つ持つ。（それぞれ B0,B1B_0, B_1B0​,B1​ とする）

(1) のクエリの場合

  • B0[l]B_0[l]B0​[l] に −v×l-v \times l−v×l、B0[r]B_0[r]B0​[r] に v×rv \times rv×r を足す。
  • B1[l]B_1[l]B1​[l] に vvv、B1[r]B_1[r]B1​[r] に −v-v−v を足す。

(2) のクエリの場合

B0B_0B0​ の [0,r)[0, r)[0,r) の和を s0s_0s0​、B1B_1B1​ の [0,r)[0, r)[0,r) の和を s1s_1s1​ とすると、s0+rs1s_0 + r s_1s0​+rs1​ が答え。

証明？

(1) のクエリが飛んできた後に (2) のクエリで正しく計算できていれば良い。 (1) で [a,b)[a, b)[a,b) に値 vvv が加算され、(2) で [0,c)[0, c)[0,c) の和を求めるとする。

c<ac < ac<a の時

(1) のクエリで加算された値は [0,c)[0, c)[0,c) には関係ないので OK。

a≤c<ba \leq c < ba≤c<b の時

  • B0B_0B0​ の [0,c)[0, c)[0,c) に加算された値は −va-va−va
  • B1B_1B1​ の [0,c)[0, c)[0,c) に加算された値は vvv

よって、s0+cs1=v(c−a)s_0 + c s_1 = v(c - a)s0​+cs1​=v(c−a) より、正しい。

b≤cb \leq cb≤c の時

  • B0B_0B0​ の [0,c)[0, c)[0,c) に加算された値は −va+vb-va + vb−va+vb
  • B1B_1B1​ の [0,c)[0, c)[0,c) に加算された値は −v+v=0-v + v = 0−v+v=0

よって、s0+cs1=v(b−a)s_0 + c s_1 = v(b - a)s0​+cs1​=v(b−a) より、正しい。

以上より、正しく区間和を計算できている。
